4-Step Quick Setup (Up & Running in 5 Minutes)

Step 1
Install Module

Install the app with 1 click in your Odoo 17.0 or 18.0 database.

Step 2
Add API Key

Navigate to AI OCR > Providers and paste your OpenAI or Claude API key.

Step 3
Test Connection

Click Test Connection to verify API credentials and latency.

Step 4
Upload & Extract

Click Scan Document or use the button directly on Vendor Bills. You're done!
