# WhatsApp Business Cloud API Enterprise Suite for Odoo 17.0 & 18.0

Official Meta WhatsApp Business Cloud API Integration Suite for Odoo.

## Key Features
- **Zero Middleman Markups:** Direct Meta Graph API (v21.0+) connection.
- **Automated In-Memory QWeb PDF Invoices:** Auto-renders and dispatches invoices on validation.
- **Real-Time Logistics Alerts:** Automatic tracking notifications upon Delivery Order validation.
- **2-Way Conversational Engine:** Bi-directional sync directly into Odoo Discuss channels.
- **Interactive Conversational Bot:** Automated Catalog display and draft quotation generation.
- **Asynchronous Queue & Failover:** ir.cron-backed message queue with exponential backoff.
- **Bank-Grade Security:** HMAC-SHA256 signature verification on webhooks.
